## 推荐的风格

### 及时清除全局副作用

 在每次 `addEventListener` 之后，记得使用，`removeEventListener` 进行移除



一个方法，尽量不超过一百行



方法的参数，至多两个，如果有更多参数，进行拆分，

函数中，避免修改传入的参数
例外：immer

if 可以提前 return，来避免更深层的 if else 嵌套

不使用过时的 API

jsdoc 文档注释

如果项目很简单，是做不出差异化的，市面上应该不缺少解决方案

如果项目很复杂，是很难简单上手的

使用 eslint 格式化代码

## 建议的风格

函数名称自解释，函数名称就描述了当前函数的作用

例如：`initTable` 初始化 table

使用 typescript 进行类型约束

一个文件夹内，最多 25 个文件+文件夹

所有 DOM 有关的事件都加上 on 前缀，比如 `onInitForm`

多写纯函数，避免副作用（使用作用域外的变量）
