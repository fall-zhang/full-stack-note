## 模块化开发

### 内联模块

```rs
// src/main.rs
mod utils {
  pub fn greet() {
    println!("Hello!");
  }
}

fn main() {
  utils::greet();
}
```

### 文件模块

使用 pub 关键字，以让外部模块可以访问该内容

```rs
// src/main.rs
mod utils;  // 对应 src/utils.rs

fn main() {
    utils::greet();
}

// src/utils.rs 文件内容
pub fn greet() {
    println!("Hello from utils!");
}
```
